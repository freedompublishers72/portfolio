# Upwork Economic Viability — Phase 1.1E Prompt Record

Exact prompt used for the Phase 1.1E Sub-phase Discovery Summary task.

---

You are executing Upwork Economic Viability Phase 1.1E — Sub-phase Discovery Summary.

INPUT

Use the completed evidence from:

- Phase 1.1A — Technical Universe Scan
- Phase 1.1B — Economic Ranking
- Phase 1.1C — Winner Deep Dive
- Phase 1.1D — Project Exploration

OBJECTIVE

Produce the consolidated discovery summary for Phase 1.1.

This is not a new research phase. It is the evidence consolidation and decision-preparation phase.

The summary must answer:

1. What technical markets were actually observed?
2. Which characteristics correlate with economically interesting projects?
3. Which technical areas survived deeper investigation?
4. Which apparent opportunities failed under deeper examination?
5. What project archetypes repeatedly appear?
6. What budget ranges are economically meaningful?
7. What project durations are compatible with the short-contract objective?
8. What competition levels were observed?
9. What are the actual Connect acquisition economics?
10. What win rates are required for viability?
11. What delivery times are required?
12. Where does technical difficulty appear to constrain effective supply?
13. Where does technical difficulty NOT constrain competition?
14. Which work appears commodity/AI-solvable?
15. Which work requires diagnosis, specialist knowledge, integration, or operational judgment?
16. Which problems recur?
17. Which problems generate follow-on work?
18. Which project structures create scope or acquisition risk?
19. What evidence remains insufficient?
20. What should happen next?

CONSOLIDATION

Separate findings into:

A. Strongly supported by observed evidence
B. Directionally supported
C. Hypotheses requiring testing
D. Unknown / unobservable

Do not convert hypotheses into facts.

ECONOMIC MODEL

Provide the consolidated economics for the most relevant project archetypes:

- typical budget
- typical Connect requirement
- acquisition cost
- competition
- plausible delivery time
- required win rate
- effective hourly economics
- recurring-demand potential

Use ranges rather than false precision.

CAPABILITY MAPPING

Only after establishing the market evidence, map the economically relevant archetypes against the existing capability universe.

Identify:

- direct capability matches
- capability combinations
- small capability gaps
- major capability gaps
- areas where additional learning would materially change feasibility

Do not redesign MIOS or WorkBot in this phase.

DECISION OUTPUT

Produce:

1. Phase 1.1 consolidated findings
2. Technical-market findings
3. Economic findings
4. Project-structure findings
5. Competition findings
6. Acquisition findings
7. Technical-difficulty/supply findings
8. AI/commodity findings
9. Recurring-demand findings
10. Short-contract findings
11. Most important project archetypes
12. Remaining uncertainties
13. Evidence gaps
14. Recommended experiments/tests for Phase 1.2
15. Explicit Phase 1.1 conclusion

The conclusion must distinguish:

- what the evidence establishes,
- what it suggests,
- and what still needs live-market validation.

Do not produce a generic "freelancing is viable" conclusion.

The objective is to determine whether there is a specific, evidence-supported economic path worth testing further.
